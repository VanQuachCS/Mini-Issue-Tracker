# Before submitting

1. Confirm a console-only application is acceptable: the task lists web, mobile, or API-based application types.
2. Install JDK 17+, compile, and run the tests exactly as described in README.
3. Run the app manually: create, view, edit, change status, filter, search, assign, delete, exit, and restart to verify persistence.
4. Review every source file and understand it; the task explicitly says you are responsible for submitted code.
5. Personalize ENGINEERING.md, especially the most difficult part, and describe any remaining limitations honestly.
6. Create a GitHub repository, commit actual work with truthful commit history, and push it.
7. Submit the GitHub URL through the employer's submission form; do not submit this ZIP alone unless requested.

Suggested initial commands:
```
git init
git add .
git commit -m "feat: implement Java console issue tracker"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
Do not fabricate historical commits. Subsequent genuine fixes, tests, and documentation edits can be committed separately.
